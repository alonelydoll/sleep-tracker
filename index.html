Publier sur GitHub Pages

Voici les étapes très simples pour rendre votre agenda accessible gratuitement sur votre téléphone et PC grâce à GitHub Pages :

1. Créer un compte & un dépôt

Inscrivez-vous sur GitHub.com puis créez un nouveau dépôt public (Repository) nommé par exemple mon-agenda-sommeil.

2. Déposer ce fichier

Enregistrez tout le code de cette page sous le nom exact : index.html.
Uploadez le fichier index.html dans votre dépôt GitHub.

3. Activer GitHub Pages

Allez dans l'onglet Settings (Paramètres) de votre dépôt ➔ menu Pages à gauche ➔ Sous Build and deployment, choisissez la branche main (ou master) puis cliquez sur Save.

4. C'est prêt ! 🌸

Après 1-2 minutes, votre site sera disponible à l'adresse :
https://votre-pseudo.github.io/mon-agenda-sommeil/.
Vous pouvez l'ajouter aux favoris de votre téléphone pour y accéder comme une vraie application !
